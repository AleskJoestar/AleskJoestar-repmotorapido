# Motorápido PLUS

Sistema web de gerenciamento de estoque, peças e serviços para oficina de motocicletas.

## Descrição

O Motorápido PLUS é uma aplicação web desenvolvida para auxiliar oficinas de motocicletas no controle de estoque de peças, cadastro de serviços e gestão de ordens de serviço. O sistema permite o cadastro de peças com controle de quantidade, valores de custo e venda, além de funcionalidades para dar baixa no estoque ao realizar serviços ou vendas.

## Objetivo

Facilitar o dia a dia de oficinas de motocicletas, proporcionando um controle eficiente de estoque e serviços, com uma interface moderna, responsiva e de fácil utilização.

## Tecnologias

- React 19
- TypeScript
- Tailwind CSS
- TanStack Start
- TanStack Router
- TanStack Query
- shadcn/ui

## Estrutura do Projeto

```
src/
  components/     # Componentes reutilizáveis (UI, tabelas, formulários)
  hooks/          # Hooks customizados
  lib/            # Utilitários e helpers
  routes/         # Rotas da aplicação (file-based routing)
  styles.css      # Estilos globais e tokens do design system
```

## Funcionalidades Previstas

- Cadastro, edição e exclusão de peças no estoque
- Controle de quantidade, valores de custo e venda
- Busca e filtros no estoque
- Dashboard com visão geral do sistema
- Gestão de ordens de serviço
- Funcionalidade de "Dar Baixa" no estoque
